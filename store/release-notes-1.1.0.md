# Typewell 1.1.0 release notes

- Added 28 offline fonts, bringing the catalog to 159 choices: 147 bundled fonts and 12 system fonts.
- Added OpenDyslexic, Inclusive Sans, and Readex Pro to the Accessible category.
- Added Albert Sans, Instrument Sans, Schibsted Grotesk, Epilogue, Onest, Gabarito, Maven Pro, Kanit, Prompt, Bricolage Grotesque, and Roboto Condensed.
- Added Cormorant, Libre Caslon Text, Noto Serif Display, Young Serif, and Prata.
- Added Martian Mono, Noto Sans Mono, Victor Mono, Unbounded, Syne, Bowlby One, Borel, Homemade Apple, and Gloria Hallelujah.
- Improved the font asset updater so unchanged verified fonts are reused instead of downloaded again.

All bundled fonts remain local to the extension. Typewell makes no font-service requests while browsing.
