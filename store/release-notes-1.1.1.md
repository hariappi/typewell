# Typewell 1.1.1 release notes

- Fixed **Use original** so it previews a website's original fonts without changing saved settings.
- The original-font choice is now saved only after clicking **Apply to this website**.
- Closing the popup restores the previously saved font, just like every other unsaved live preview.

All fonts and settings remain local. Typewell has no analytics and makes no font-service requests while browsing.
