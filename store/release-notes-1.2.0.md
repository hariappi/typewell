# Typewell 1.2.0 release notes

- Added System, Light, and Dark themes for the popup and Preferences page. System mode follows Firefox and your operating system automatically.
- Removed the popup's separate font sample so more fonts are visible. The open website remains the live preview.
- Improved dark-theme contrast for controls, selected fonts, messages, dialogs, and focus indicators.

All fonts and settings remain local. Typewell has no analytics and makes no font-service requests while browsing.
