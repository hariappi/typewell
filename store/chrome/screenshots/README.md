# Typewell Chrome Web Store screenshot

`typewell-live-preview-1280x800.png` and `.jpg` are 1280 × 800, RGB images.

The image combines two actual captures from the same live preview in Brave: the installed Typewell 1.2.3 popup and an original local reading sample. Lora was selected with live preview enabled. The heading and paragraph computed font families were verified as `"Typewell Lora", serif`. The captures were cropped, resized, and placed together for the listing; no UI was recreated.

Original captures are retained as `typewell-popup-source.png` and `typewell-page-source.jpg`. The sample page is in `../demo/index.html`. No persistent font rule was saved.

The image has been prepared locally and has not been uploaded or submitted to the Chrome Web Store.
